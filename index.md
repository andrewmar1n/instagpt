# InstaGPT

**Desktop Calendar & Scheduling Application**

InstaGPT is a desktop application for managing calendars, events, bookings, and scheduling.

### Google Calendar Integration

InstaGPT allows users to securely connect their Google accounts and synchronize calendar events between Google Calendar and the application.

The integration supports reading, creating, updating, and deleting calendar events with user authorization.

### Application Status

InstaGPT is currently under development and intended for private desktop use.
