InstaGPT — Privacy Policy

Last updated: October 21, 2026

1. About InstaGPT

InstaGPT is a desktop application for calendar management, scheduling, and event synchronization. It is currently developed for private use.

2. Google Calendar Data

With user authorization, InstaGPT accesses Google Calendar data to read, create, update, and delete calendar events and synchronize them with the desktop application.

3. Data Storage and Security

Calendar events and synchronization metadata are stored in the application's local database. OAuth credentials are stored using the application's encrypted credential storage.

Automatic synchronization may use a webhook relay server to receive calendar change notifications. Calendar event contents are retrieved through the authorized Google Calendar API.

4. Data Usage and Sharing

Google Calendar data is used for calendar and scheduling functionality. It is not sold to third parties or used for advertising.

InstaGPT's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Data Retention and Deletion

Calendar data remains in the local application database until it is deleted through the application's supported data management functions or the local database is removed by its owner.

Google account access can be revoked through Google Account security settings. Revoking access prevents further authorized synchronization but does not automatically remove previously stored local data.
